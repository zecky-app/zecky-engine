# Security

This is the Zecky engine: the Zcash light-client engine used by Zecky Lock
it and Zecky Pocket. If you find a security problem in it, please tell us
privately first.

- Email **dev@zecky.app**, or use GitHub's private vulnerability reporting
  on this repository.
- Please do not open a public issue for a security problem.

A problem in the official Zcash core itself (librustzcash, the crates this
engine is built on) belongs with the Zcash developers: see
`responsible_disclosure.md`, kept from the upstream SDK. If you are unsure
which it is, write to us and we will pass it on.
